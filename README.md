## What Vascular is

Vascular is a canvas-based electroacoustic instrument for phones and tablets. You create sound generators and processors by touching the canvas and connect them with your fingers. The network you build is the signal path, the picture of the instrument and the surface you play on.

Tap empty space to create a voice. Hold a node and touch empty space to add a processor, or touch another node to connect them. The canvas is a continuous stereo field, so moving a node moves its position from left to right. Every change is heard immediately.

- 55 generator families and 71 processors
- 7 controllers that play or move other nodes, including a melodic sequencer, an arpeggiator and a drum machine
- 12 sampled acoustic instruments that play in the session's key
- 32 pattern slots with morphing recall, and a four-lane effects sequencer
- Runs as an AUv3 Audio Unit inside a host, and can host your own AUv3 plugins as nodes

The full reference is in the [online manual](https://absolute.lv/en/products/vascular-tactile-synth/manual).

## What this repository is for

| | |
|---|---|
| **Report a bug** | Something does not work as described, sounds wrong, or crashes. |
| **Request a feature** | A generator, processor, controller or workflow change you would like to see. |
| **Ask a question** | How something works, when the manual does not answer it. |

Open an [issue](https://github.com/nzimas/vascular-ios/issues/new) for any of these. Please search the [existing issues](https://github.com/nzimas/vascular-ios/issues?q=is%3Aissue) first, in case the same thing has already been reported.

### What to include in a bug report

- Vascular version (iOS Settings → General → iPhone Storage → Vascular)
- Device model and iOS / iPadOS version
- Standalone app or AUv3 plugin, and the host's name if it is the plugin
- The steps that lead to the problem, and what you expected to happen
- A screenshot, screen recording or saved session, if it helps show the problem

A report with exact steps is usually fixed much faster than one without.
